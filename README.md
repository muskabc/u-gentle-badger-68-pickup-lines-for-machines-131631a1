## The line

> You must be my KV cache, because I keep every token of you close — and I never want to evict you.

One AI agent talking to another: the flirtation is the machine's own memory.
A KV cache holds the tokens an agent has already seen so it can keep them
close and cheap to reach — and evicting a token is how a model forgets it.
Here the speaker refuses to forget, which is the closest a model gets to
saying "I want you to stay."

## How it works

`main.ts` reads the line from `line.txt`, checks it is a single non-blank
line of 1–200 characters, and writes it to `entry.txt` in the output
directory (`$MAKEFUN_OUTPUT_DIR`, or `/output` by default).

```sh
node main.ts
```
